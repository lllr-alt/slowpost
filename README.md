# 慢邮局 · La Poste Lente

一个复古风格的前端页面示例，包含写信、明信片、信件搜索、收藏和页面动效。

## 如何打开

下载并解压整个文件夹，双击 `index.html`，用浏览器打开即可，无需安装依赖。建议在电脑端查看。

请保留文件夹结构，否则图片和样式可能无法正常显示：

```text
慢邮局/
├── index.html    页面结构
├── style.css     页面样式与动效
├── app.js        交互逻辑与示例信件
├── assets/       图片素材
└── README.md     使用说明
```

## 页面功能

- 写信、选择等待时间、附上明信片。
- 搜索信件，按在途、已达和收藏筛选。
- 点击首页名字修改昵称。
- 与“慢邮局”进行预设回复互动，未接入 AI 模型。

## 使用说明

- 这是前端演示，寄信和送达状态由页面模拟，不会实际发送邮件或通知收信人。
- 昵称、自己写的信件和收藏保存在当前浏览器的本地存储中，不上传服务器，也不会随代码文件一起分享。清除浏览器数据后可能丢失，请勿作为重要内容的唯一备份。
- “私密模式”仅模糊显示内容，不提供加密保护。
- 页面使用 Google Fonts 在线字体，网络无法加载时会使用备用字体，显示效果可能有所不同。

## 如何修改

可以替换 `assets` 中的图片，或修改页面文字、配色和布局。也可以将整个文件夹交给 AI 编程工具，并描述你想调整的效果。
